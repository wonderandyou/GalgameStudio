# 交接格式（每人一个文件）

> 文件路径固定：`D:\软件\GalgameStudio\docs\handoff\<你>.md`
> 名字：`kimi.md` / `astra.md` / `grok.md` / `workbuddy.md`

---

## 模板（复制这段，填了再交）

```markdown
# <你的名字> 交接 · <日期时间>

## 我做了什么
- `相对路径\文件.py`：一句话说清改了什么、为什么

## 验证结果（必须是真的跑过）
| 命令 | 结果 |
|---|---|
| `<命令>` | `<关键输出，比如 PASS / Ran 6 tests OK / 27/27>` |

跑过截图的话把图放到 `docs\screens\<你>\`，在这里写文件名。

## 发现但没改的（交给经理转）
- 现象：
- 在哪个文件：
- 我建议怎么改：
- 为什么我没改：（超出我的文件边界 / 需要改契约 / 不确定）

## 给下一位的注意事项
- 比如：我新加了一个路由文件，记得在 main.py 里 include
```

---

## 判罚标准（经理验收时会照这条看）

| 情况 | 判定 |
|---|---|
| 没写 handoff | **等于没做完**，不算交付 |
| 写了"应该没问题" | 当作没验证，打回重跑 |
| 改了边界外的文件 | 打回，并要你说明原因 |
| 说是改了但其实没改 | 打回 |
| 跑了但没说怎么跑 | 补充验证方式 |
| 汇报里出现密钥原文 | 严重违规，立刻从记录里清掉 |
