
Python：`D:\软件\GalgameStudio\app\.venv\Scripts\python.exe`
起后端：`powershell -ExecutionPolicy Bypass -File D:\软件\GalgameStudio\scripts\run-backend.ps1`（端口 8790）
Unity：`D:\Unity\6000.0.85f2\Editor\Unity.exe`

## 二、文件边界（**最重要的一条**）

| 谁 | 只能改 | 绝对不许碰 |
|---|---|---|
| **Kimi** | `ui\**` | `app\**`、`tools\**`、`projects\**` |
| **Astra** | `app\**`（除 `contract.py`） | `ui\**`、`tools\**`、`app\engine\export_*.py` |
| **Grok** | `tools\**`、`app\engine\export_*.py`、`D:\UnityProject\**` | `ui\**`、`app\contract.py`、`app\providers\*`（除 image.py） |
| **WorkBuddy** | `docs\handoff\workbuddy.md`（只写这一个文件） | 其它所有文件 |
| **经理** | `app\contract.py`、`docs\协作\**`、git 操作 | — |

**为什么这么切**：四个人同时改同一个文件，必然冲突且没法回退。
你要改别人的文件 → **不要改**，写进你的 `docs\handoff\<你>.md`，经理来转。

## 三、接口契约（前后端照同一份写）

完整版见 `docs\协作\10-接口契约.md`。摘要：

```
POST   /api/projects/{pid}/references       上传参考图（multipart: file, kind=character|scene, label）
GET    /api/projects/{pid}/references       列出参考图
DELETE /api/projects/{pid}/references/{id}  删除参考图（只删登记）
POST   /api/projects/{pid}/voices           上传语音素材（multipart: file, character_id, label）
GET    /api/projects/{pid}/voices           列出语音
DELETE /api/projects/{pid}/voices/{id}      删除语音
GET    /api/projects/{pid}/library          素材库总列表
POST   /api/projects/{pid}/export           body.format 增加 unity
```

**Kimi 按这份写 UI，Astra 按这份写接口** —— 谁都不许自己改形状。
觉得契约有问题 → 写进 handoff，经理决定后统一改。

## 四、交接方式（你们之间唯一的沟通）

干完活在 `D:\软件\GalgameStudio\docs\handoff\<你>.md` 写（格式见 `90-交接格式.md`）：

```markdown
# <你的名字> 交接

## 我做了什么
- 文件 + 一句话做了什么

## 验证结果（必须是真的跑过）
- 命令 + 关键输出（不许写"应该没问题"）

## 发现但没改的（交给别人）
- 现象 / 在哪个文件 / 建议怎么改

## 给下一位的注意事项
```

**没写 handoff 等于没做完** —— 经理只认文件。

## 五、共同的禁令

1. **不许 `git` 任何操作**（commit / checkout / reset / stash 都不行）—— 经理统一管
2. **不许删 `projects\` 下任何东西**
3. **不许 `pip install` 新包**（要用现成的；确需新包写进 handoff 让经理装）
4. **不许改 `app\contract.py`**（extra='forbid'，加字段给默认值这件事只有经理做）
5. **不许动凭据**：`~/.dsh/.credentials.yaml` 只读，代码里绝不写 key
6. **不许说"应该没问题"** —— 没跑过就写"未验证"
