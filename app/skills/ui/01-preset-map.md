# 关键词 → 预设：怎么判断该选哪套

界面的选型不是审美投票，是**把故事的情绪翻译成视觉语言**。
同一个词在不同上下文里可能落到不同预设 —— 这份表给判断依据，不是死规则。

---

## 一、按「情绪温度」先分两半

```
冷 / 低饱和 ──────────────────────────── 暖 / 高明度
   theater-cold      cinema-dark    ink-classic    paper-indie
   最冷               中间偏冷        中间偏暖        最暖最亮
```

先判断故事整体是冷是暖，再在那一侧挑。
**用户给的第一个词往往最准** —— 人描述画面时第一句是直觉。

---

## 二、四套各自的「专属词」（命中最强）

| 预设 | 专属词（见到基本就定它） |
|---|---|
| `ink-classic` | 水墨、宣纸、书法、毛笔、竖排、印章、江南、年代、民国 |
| `cinema-dark` | 电影感、全幅、剧照、雨夜、港口、都市、硬派、大气 |
| `paper-indie` | 清新、明亮、校园、青春、治愈、轻小说、手帐、干净 |
| `theater-cold` | 冷色调、压抑、孤独、剧场、细线框、深蓝、科幻、末日 |

---

## 三、容易误判的五种情况

### 1. 「悬疑」——四套里三套都能接
`ink-classic`（年代悬疑）、`cinema-dark`（都市犯罪）、`theater-cold`（心理悬疑）都写了 `悬疑`。

**判断方法：看第二个词。**
- 「悬疑 + 民国/古镇」→ `ink-classic`
- 「悬疑 + 夜晚/城市」→ `cinema-dark`
- 「悬疑 + 精神病院/记忆」→ `theater-cold`

### 2. 「日常」——两套都能接
`ink-classic`（安静的日常）和 `paper-indie`（明亮的日常）。

**判断方法：看明暗。**
故事发生在黄昏/雨天的旧街 → 水墨；发生在教室/晴天 → indie。

### 3. 「雨夜」——只在 `cinema-dark`
虽然是水墨也能画雨，但 `雨夜` 已被归到电影感那一套。
**用户说「雨夜 + 江南」时**，两个预设都会命中，
这时看用户要的是「氛围」还是「气质」：
- 「江南雨夜的旧事」→ 水墨（讲回忆、讲人）
- 「雨夜港口的一场交易」→ 电影感（讲事件、讲场面）

### 4. 用户给的是**题材**而不是氛围词
例如「校园恋爱」「末世求生」。`match_ui_preset` 也能匹配 `fit` 字段，但权重较低。

这时**主动把题材翻成氛围词再匹配一次**：
「校园恋爱」→「校园 清新 青春」→ `paper-indie`
「末世求生」→「末日 压抑 孤独」→ `theater-cold`

### 5. 用户给了完全接不住的词
例如「赛博朋克霓虹粉紫」「蒸汽波」。

`cinema-dark` 的 keywords 里有 `赛博`，能接住一半；剩下「霓虹粉紫」没有。
**这时要说清楚**：「有 `cinema-dark` 最接近，但它不是霓虹配色；
要不要在它上面微调强调色？还是换一套？」

---

## 四、什么时候才动 `tweak_ui_preset`

**只有三种情况允许微调：**

| 情况 | 允许改什么 | 例子 |
|---|---|---|
| 预设对了，但强调色跟作品不符 | `accent` | 水墨套配朱红，但故事主题是青瓷 → 改 `#2f6f6a` |
| 标题太长，原字号装不下 | `title_size` | 8 字标题在 82px 下溢出 → 降到 68px |
| 用户明确要求菜单换个方向 | `menu` | 「菜单想横着放」→ `horizontal` |

**不允许的**：改底色（换预设）、改字体（预设的字体是一体的）、
改了一堆再说是「微调」。

---

## 五、回报时怎么说

合格的说法：

> 按「江南 雨夜 旧事」选了 `ink-classic`（水墨直系）——
> 命中「江南」「雨夜」；这套是宣纸底 + 毛笔竖排 + 红色印章，
> 和旧街回忆的调子对得上。启动页已渲好，截图核对过：
> 竖排菜单四列整齐，立绘压在纸边没有压字。

不合格的说法：

> 已经生成好了，应该没问题。
