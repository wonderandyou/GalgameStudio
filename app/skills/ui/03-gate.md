# 验收关卡：什么算过关，什么必须重做

`check_ui` 是机器能查的那一半；这一篇是机器查不了、但必须你自己看一眼的那一半。

---

## 一、机器查的（`check_ui`）

| 检查项 | 不过会怎样 |
|---|---|
| 是否渲染过 | 一条都没渲，等于没干活 |
| HTML 文件是否存在 | 路径记了但文件没了 |
| 有没有残留占位符 | 模板没替换干净，界面会显示 `$bg` 这种字 |
| 菜单项 ≥ 2 | 只有一项的「菜单」是摆设 |
| 图片引用是否真存在 | 背景图路径写错 → 界面一片空白 |
| 标题字号 ≥ 40 | 太小等于没标题 |
| 强调色是否出现在 HTML | 说明这次可能没套预设 |

**`issues` 不为空 = 没过。** 修完重跑，直到为空。

---

## 二、机器查不了、必须你自己看的

### 1. 标题有没有被裁掉
竖排预设里标题一长就顶出画面。截图看**标题最后一个字是否完整**。

### 2. 菜单有没有折行 / 错位
竖排菜单每项应该是一列。如果某项被拆成两列（`开始游戏` 变成 `开始` 和 `游戏` 两列），
就是容器高度不够 —— 这是真实的坑，踩过一次。

### 3. 立绘有没有压到字
`ink-classic` 的立绘在两侧、菜单在左中、标题在中间。
三者一旦重叠，字的可读性立刻掉下来。

### 4. 背景是不是加载了
没加载时是纯色底 —— 看着「干净」，其实是破了。
**深色预设要特别看**：没背景时它和「压暗的背景」很像，容易看漏。

### 5. 字清不清楚
- 深色底上不要用细体 + 低对比（会糊）
- 米白底上不要用浅灰（对比度不够）
- 标题和副标题不要同色同重

---

## 三、四套预设各自的「重点看哪里」

| 预设 | 重点 |
|---|---|
| `ink-classic` | 竖排菜单每项是否一列；立绘是否压字；印章位置是否贴着标题下沿 |
| `cinema-dark` | 背景是否够暗（白字要能看清）；底部横排菜单是否挤成两行；金色细线是否在副标题下方 |
| `paper-indie` | 斜切边缘是否平滑；右侧按钮在深色图上是否看得见；编号 01–04 是否对齐 |
| `theater-cold` | 细线框四边是否等距；居中标题的字距是否均匀（首尾不要忽宽忽窄）；选项半透明底在亮背景上是否糊 |

---

## 四、必须重做的情况

| 现象 | 原因 | 怎么修 |
|---|---|---|
| 菜单折成两列 | 字号太大 / 容器太窄 | 缩字号或改用横排预设 |
| 标题顶出画面 | 字数超了 | 缩 `title_size`，或换短标题 |
| 字看不清 | 深色预设 + 浅背景 | 换背景图，或换预设 |
| 按钮消失在背景里 | `paper-indie` 的右下角压在图上 | 换 `cinema-dark`，或换更暗的图 |
| 六块皮像两个游戏 | 中途换了预设 | 全部用同一个 preset id 重渲 |

---

## 五、交付前最后一句自检

> 「如果用户现在打开这张图，他能不能一眼看出这是**同一个作品**的界面？」

如果启动页和对话框看起来像两个游戏，就是没过 —— 不管 `check_ui` 有没有报错。
