# 验收关卡：什么算过关，什么必须重画

---

## 一、两道自动检查

| 检查 | 查什么 | 不合格怎么办 |
|---|---|---|
| `check_consistency` | 同角色跨节点是否同一张、配色是否统一 | 只重生跑偏那一张 |
| `check_style` | 风格圣经是否齐、`look` 是否为空、背景是否套用前缀 | 补字段 / 重出 |

**两道都零问题**才算这批过。

---

## 二、肉眼三项比对

自动检查只能查元数据，画面本身要自己看：

| 项 | 怎么看 | 不合格 |
|---|---|---|
| 色板 | 图里主要颜色是否都在 `palette` 里 | 出现第三种主色 → 重出 |
| 光影 | 亮部 / 暗部方向是否跟 `light` 一致 | 光源乱 → 重出 |
| 构图 | 人物位置、底部留白、有没有文字 | 有文字 / 多人 → 重出 |

**对比方法**：把新图和同组第一张并排看，问一句
「这两张是不是同一个人画的？」—— 不是就重出。

---

## 三、重画的边界

| 情况 | 重画范围 |
|---|---|
| 单张跑偏 | 只重画这一张 |
| 整个角色跑偏 | 重画这个角色的全部 |
| 风格圣经定错 | **全部重画**，并 `set_style(overwrite=true)` |
| 素材库命中但色调不对 | 不用库里的，重出 |

**不许「凑合能用」** —— 一张不搭的图会被玩家一眼看出来。

---

## 四、失败处理的优先级

```
1. 先重试一次（可能是网络抖动）
2. 还不成 → 调 negative 补词
3. 再不成 → 换更具体的 brief
4. 连续 3 次不成 → 停下报告，别烧额度
```

---

## 五、收尾总检查

- [ ] `check_consistency` 零问题
- [ ] `check_style` 零问题
- [ ] 每个 bg_key 一张图
- [ ] 每个角色 ≤ 4 套立绘
- [ ] 六个 surface 都出了
- [ ] 随机抽 3 张并排看，像同一个人画的
- [ ] 没有任何一张带文字或水印
