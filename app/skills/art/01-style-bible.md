# 风格圣经：全片唯一的视觉输入源

---

## 一、为什么只能有一份

没有它，会发生这些事：

| 现象 | 后果 |
|---|---|
| 第 1 章背景是冷蓝调，第 20 章变成暖橙调 | 玩家感觉「换了部游戏」 |
| 立绘用厚涂，界面用扁平 | 对话框像贴在别人游戏上 |
| 每张图的负面词都不一样 | 有的图有文字水印，有的没有 |

这些**不是画得不好，是没有统一基准**。
一旦出到 50 张以上，回头统一等于全部重画。

所以 `set_style` 必须在 `generate_image` 之前调，而且只调一次。

---

## 二、五个字段怎么填

调 `set_style` 时给这五项，缺一项后面都会跑偏。

### 1. `palette` —— 色板（至少 4 色，最多 6 色）

按这个顺序给：

| 位次 | 用途 | 例子 |
|---|---|---|
| 主色 | 画面基调、大面积色 | 深夜蓝 `#1a1a2e` |
| 辅色 | 次级区域、阴影 | 深靛 `#16213e` |
| 强调色 | 关键物件、UI 高亮 | 朱红 `#e94560` |
| 中性色 | 文字、留白 | 米白 `#f5f5f5` |

**从需求里怎么推**：

- 题材决定冷暖 —— 校园日常偏暖、悬疑偏冷、末世偏灰浊
- 时间段决定明度 —— 夜戏整体压暗，白戏提亮
- 情绪决定强调色 —— 压抑用低饱和，激烈用高饱和

### 2. `medium` —— 画法

一句话，写**笔触和线**，不写「好看」：

```
✓ 赛璐璐，细描线，色块干净
✓ 厚涂，笔触明显，不打线稿
✓ 水墨，边缘晕染，留白多
✗ 精美的二次元风格（模型听不懂，等于没写）
```

### 3. `light` —— 光影基调

写**色温 + 对比 + 主光方向**：

```
✓ 冷调，低对比，侧逆光，暗部保留细节
✓ 暖调，高对比，顶光，硬阴影
✗ 氛围感拉满（这是感想，不是参数）
```

### 4. `typeface` —— 字体方案

标题 / 正文 / UI 三档，各给一个名字：

```
标题 思源宋体 Bold；正文 思源黑体 Regular；UI 思源黑体 Medium
```

### 5. `negative` —— 全局负面词

每张图都会带上。**至少包含这几类**：

```
文字、水印、签名、过曝、写实照片感
```

不要写「丑」「难看」—— 模型不知道判定标准。

---

## 三、定完之后

- 每张图都必须走 `draft_prompt`，它会自动带上 palette / medium / light / negative
- 中途要换风格：用 `set_style(overwrite=true)`，但**已出的图要全部重画**
  —— 只换一半，比没有风格更难看

---

## 四、自检

- [ ] palette 至少 4 色，且都是合法十六进制
- [ ] medium 写的是画法，不是形容词
- [ ] light 写了色温 / 对比 / 主光
- [ ] typeface 三档都有
- [ ] negative 包含 文字 / 水印 / 过曝
