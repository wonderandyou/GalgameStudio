# 立绘：让同一个角色在第 30 章还是她

---

## 一、外形锚点必须逐字复用

角色表里有一个 `look` 字段，那是她的**外形锚点**。

> **这个字段从哪来？** 用户传了参考图 → 看图写；**没传图 → 得你自己造**，
> 而且必须写成「名词 + 数字」、写不出形容词。具体怎么造见 `08-no-reference.md`。

```
heroine: 短发，米色风衣，左耳一颗小痣，习惯把袖子撸到手肘
```

**每张立绘的提示词里都必须原样带上这一段**，一个字不许改。

改了会怎样：

- 第 1 章「短发」→ 第 30 章「齐肩发」→ 玩家认不出是同一个人
- 换个词序，模型就可能把「米色风衣」画成「米白大衣」

所以 `look` 不是给人看的备注，是**生图输入的一部分**。

---

## 二、立绘 prompt 的固定结构

```
[风格前缀（draft_prompt 自动拼）] + [标准立绘前缀] + [look 逐字] + [姿态/情绪] + [纯色背景]
```

调 `draft_prompt(target='character', brief=...)` 会自动给你风格前缀和首尾两段，
你只需要往 `brief` 里填**姿态 + 情绪**：

```
✓ brief = 站立，双手插兜，低头侧脸，情绪平静
✗ brief = 一个漂亮的女孩站在雨里，很伤心（没姿态、没正面、还带背景）
```

---

## 三、状态克制：一个角色 2~4 套

| 状态 | 用途 |
|---|---|
| 平静（stand / neutral） | 80% 的节点 |
| 情绪波动（哭 / 怒 / 笑） | 关键情节 |
| 特殊（背身 / 低头 / 侧脸） | 少数镜头 |

**不要给每一句台词配一套新立绘** —— 玩家注意不到，成本却翻几倍。

超过 4 套先问自己：这一套真的会出现在 10 个以上节点吗？
不会就砍掉。

---

## 四、差分：改表情，不重画人

同一角色同一姿态，只换情绪时：

1. 先用 `generate_image` 出**基础套**（stand / neutral）
2. 后面的情绪套用同一个 `look` + 同一个姿态词，只改情绪词
3. 每出一套都跑一次 `check_consistency`

这样几套立绘会像同一个人，而不是几个画师各画一张。

---

## 五、一致性检查看什么

`check_consistency` 查三件事：

| 检查项 | 不合格的表现 |
|---|---|
| 同一角色跨节点来源 | 有的节点用 A 图、有的用 B 图，脸不一样 |
| 配色差异 | 同一个人衣色在不同节点变了 |
| 背景风格漂移 | 同一 `bg_key` 的两张图色调差太远 |

发现问题：**只重生有问题的那一张**，不要全批重来。

---

## 六、自检

- [ ] 每个角色 `look` 非空
- [ ] 每张立绘都逐字带上了 `look`
- [ ] 单角色状态 ≤ 4 套
- [ ] 立绘背景是纯色，不是场景
- [ ] `check_consistency` 零问题
