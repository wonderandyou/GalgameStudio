# 立绘差分：一个角色为什么不能只有一张脸

一个角色从头到尾一张脸，玩家第三章就看腻了 —— 而且「她坐在长椅上哭」配一张
「站着你笑」的立绘，画面和台词直接打架。

差分就是给同一个角色出**几张不同姿态 / 表情**的图，共用一张「基底」保证长相不跑。

---

## 数据从哪来

剧本里每个节点都带角色条目：

```json
"chars": [{"id": "heroine", "pose": "坐下", "pos": "center", "mood": "微微一笑"}]
```

- `pose` 是**姿态描述**（中文），会被归一成 `stand / sit / lean / lie / walk`
- `mood` 是**表情描述**（中文），会被归一成 `neutral / smile / sad / angry / surprise / blush / cry`

两者都**原样保留**在节点上（`mood` 存中文给界面显示，`stance` 存枚举给素材库算账）。
所以你不需要自己分类，写台词时按角色实际动作写就行。

---

## 顺序：先基底，后差分

```
list_pending_assets
  ├─ bases[]        ← 先画这些（每角色一张，透明底）
  ├─ backgrounds[]  ← 背景
  └─ poses[]        ← 再画这些（角色 × 姿态 × 表情，一格一张）
```

**基底没出，`poses` 会是空的。** 这不是 bug —— 差分要拿基底当参考图（图生图），
没有基底就没有长相锚点，画出来的会像另一个人。

所以：`bases` 清空之前，别去调 `poses`。

---

## key 怎么写

| 要画什么 | `generate_image` 的 key |
|---|---|
| 角色的基底立绘 | `heroine`（裸角色 id） |
| 「坐 + 微笑」这一格 | `char:heroine:sit:smile` |

差分 key **原样从 `poses[].key` 取**，不要自己拼 —— 拼错了会报
`没有节点在用「…」这个组合`。

---

## 差分为什么能和基底长得一样

内部做的事：把基底 PNG 当 `reference_images` 传给生图模型，提示词里写明这是同一个角色的
姿态变化。透明底也跟着继承（基底已经是抠好的透明图）。

**你不需要自己传参考图。** 传了反而会把用户上传的外形参考图挤掉。

---

## 预算

```python
BUDGET = dict(bg=40, char=8, pose_per_char=12)   # app/assets/library.py
```

每个角色最多 **基底 1 张 + 差分 12 张**。

`list_pending_assets` 的 `poses` 已经按「覆盖节点数」从多到少排 —— 先画前面的，
一张图覆盖的节点越多越划算。超出预算的组合**不用画**，会一直用最接近的那张，
这是有意的取舍（140 节点的项目全画满，光立绘就要几百张）。

---

## 常见错

| 做法 | 后果 |
|---|---|
| 跳过 bases 直接画差分 | 会报 `BASE_ART_MISSING`，强行画等于换了个角色 |
| 自己拼 `char:heroine:坐着:笑` | 枚举对不上，报「没有节点用这个组合」；用 `poses[].key` |
| 每个节点都想单独出一张 | 会撞预算，而且大部分节点之间根本没有姿态差异 |
| 重画基底想顺便刷新差分 | **不会**冲掉差分（有保护），差分要单独重画 |
| 差分时自己塞参考图 | 会覆盖基底参考，角色长相可能漂 |

---

## 验收时看什么

1. 同一角色的几张图，**脸和发型是同一个**（不是「风格相似」，是同一个）
2. 差分图的透明底和基底一样干净（边缘没有白边）
3. 「坐了」的图里人物真的是坐姿，不是站着的轮廓
4. `check_consistency` 不再报「立绘与角色表不一致」——
   差分化之后那条判据换成了「文件在不在 + 张数超没超预算」
