# 无参考图：只凭一句提示词造出全片

用户可能只填一行需求（「雨夜天台，两个人沿着一封信查明往事」），
**不上传任何图，也没接配音**。

这条路和有参考图走法不同 —— 差别不在工具，在**「先凭空造出一个基准，然后死死锁住它」**。

有参考图时，一致性来自「照着那张图画」；
没有参考图时，一致性只能来自下面三根柱子，**缺一根就崩**：

| 柱子 | 做法 | 崩了会怎样 |
|---|---|---|
| **一份外形锚点** | `look` 逐字复用，一个标点都不改 | 第 3 章换脸 |
| **一张基准图** | 每个角色先出「定妆照」，后续差分拿它做 I2I | 立绘各有各的画风 |
| **一个固定种子** | 同角色同 seed，不每张重抽 | 同一表情每张都不同 |

---

## 一、先造人：把需求变成「外形锚点」

`look` 不是给人看的备注，是**生图输入的一部分**。它得写成**能被照着重画的**样子。

### 五要素（缺一个就会飘）

| 要素 | 好例子 | 缺了会怎样 |
|---|---|---|
| 发型发色 | `黑色及腰直发，中分，发梢微卷` | 第 3 章变成齐肩发 |
| 眼睛 | `深褐色瞳孔，单眼皮` | 特写换个眼型就不像她 |
| 常服 | `白衬衫，藏青百褶裙，黑色短袜` | 衣色一漂就是另一个人 |
| 体型身高 | `身高约 165cm，偏瘦` | 构图比例前后不一 |
| 年龄气质 | `十七八岁，神情安静，不爱笑` | 脸越画越成熟或越幼 |

### 禁用词（写了等于没写）

> `漂亮` `可爱` `唯美` `精致` `气质出众` `很有魅力`

这些词**每次画出来的都不一样** —— 模型对它们的理解是浮动的。
外形锚点要的是**名词和数字**，不是形容词。

### 对照

```
✗ 一个漂亮的黑长直女孩，穿着校服
✓ 黑色及腰直发中分，深褐瞳单眼皮，白衬衫配藏青百褶裙，身高约165cm偏瘦，
  十七八岁神情安静
```

第二版能被两个不同的 provider 画成同一个人；第一版不能。

**需求里没写的外形，你自己定，但定了就不许改。** 定完写进角色表，
后面每一张图都逐字带上。

---

## 二、定妆照：每个角色先出一张，之后都拿它当参考

没有用户图时，「参考图」由你自己造 —— 顺序不能反：

```
1. 出「定妆照」：全身、正面、自然站姿、纯色背景
   （这是该角色唯一的外形基准，写进 base）
2. 之后再出任何差分（表情 / 动作 / 半身）
3. 差分一律拿 base 做图生图 → 见 07-pose-diff.md
```

**跳过第 1 步直接画差分，等于每一张都是新角色。**
代码里会报 `BASE_ART_MISSING`，那不是拦你，是在救你。

定妆照的构图建议（这几条是实践中最好用的）：

| 项 | 值 | 为什么 |
|---|---|---|
| 取景 | 全身，头顶留 5% 余量 | 半身照没法用来做差分基准 |
| 朝向 | 正面，正视镜头 | 侧脸基准没法推其他角度 |
| 姿态 | 自然站姿，双手垂下 | 有动作的基准会把动作固化到所有差分里 |
| 背景 | 纯色（浅灰或白） | 带场景的基准抠不干净 |
| 表情 | 平静 | 基准应该是「零状态」，情绪靠差分加 |

## 三、背景：从剧情反推「几个地方」，不是逐节点画

没有参考图时，背景不是「按需求画一张」，而是**扫一遍所有节点归并地点**：

```
扫全部节点的 bg_prompt
  → 归并成 15~30 个地点（一个 bg_key = 一个地方）
  → 每个地点写一份「空间锚点」
  → 按 bg_key 各出一张
```

### 空间锚点五要素

| 要素 | 例子 |
|---|---|
| 时段 | `深夜，雨` |
| 视角 | `平视略仰` |
| 光源方向 | `左上方天际泛紫蓝微光` |
| 地面/材质 | `水泥地，有积水反光` |
| **一个记忆点物件** | `栏杆上挂着一串没亮的小灯泡` |

最后那条最容易被忽略，但它最有用：
**同一地点在白天/雨夜/回忆里出现时，玩家靠这个物件认出「还是这里」。**
没有它，换一个时段就像换了个地方。

背景里**不许有人物、文字、水印**（见 `02-background.md`）——人物是叠上去的。

## 四、没有配音怎么办

`voice` 拿不到 provider（没 key / 没接）时，**不是「跳过配音」，而是「按正确时长放静音」**。

### 时长怎么算

代码里的口径是 **4.5 字/秒**（`_duration(text) = round(len(text) / 4.5, 3)`）：

| 台词字数 | 静音时长 |
|---|---|
| 9 字 | 2.0 s |
| 18 字 | 4.0 s |
| 36 字 | 8.0 s |

**必须按时长给静音，不能给 0 秒。** `dur = 0` 会让播放器卡死。

### 静音的规矩

1. **每句都占位**，不要整章跳过 —— 否则玩家的阅读节奏会乱（有的句子停、有的句子秒过）
2. 格式跟真配音一致：`24 kHz / 16-bit / 单声道 WAV`（契约测试会查这个）
3. 节点状态标 `done`，但导出报告里**明确写「本次无配音」**
4. **不许伪造语音**（不要拿系统朗读硬塞，音色和风格会跟画面打架）

降级不是失败 —— 玩家能顺畅读完，比卡在一句配音上强。

## 五、这条路的验收清单

- [ ] 每个角色 `look` 非空，且**五要素齐**（发 / 瞳 / 衣 / 身 / 气）
- [ ] `look` 里没有禁用形容词
- [ ] 每个角色都有定妆照（base），且是全身正面纯色底
- [ ] 所有差分都拿 base 做 I2I，没有跳步
- [ ] 每个 `bg_key` 一张图，且带记忆点物件
- [ ] 背景里没有人、没有文字
- [ ] 语音要么是真的，要么**全句静音占位 + 时长按 4.5 字/秒**
- [ ] 没有 `dur <= 0`
- [ ] 导出报告写明「无参考图模式」「无配音模式」
- [ ] `check_consistency` / `check_style` 零问题

## 六、常见崩坏与原因

| 现象 | 真正的原因 | 修法 |
|---|---|---|
| 第 3 章主角换了张脸 | `look` 被临时改写或省略 | 逐字复用，禁止改写 |
| 同一个天台出 40 张不同的图 | 按节点画背景，没归并 `bg_key` | 归并后一地点一张 |
| 立绘像几个画师各画一张 | 差分没拿 base，各画各的 | 先出定妆照 |
| 同一地点换时段就认不出 | 没写记忆点物件 | 补一个「不属于场景功能」的物件 |
| 台词念得太快 / 停太久 | 时长用了固定值或 0 | 按字数 ÷ 4.5 重算 |
| 角色「越画越漂亮」 | `look` 里混了形容词 | 换成名词 + 数字 |

---

## 七、一句话总结

> **有参考图时，你是在「复制一个人」；没有参考图时，你是在「定义一个人」——
> 定义完就必须一字不改地执行它。**
