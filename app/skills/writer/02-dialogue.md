# 台词的味道

Galgame 的台词不是小说，是**一句一句显示在屏幕上、玩家点一下才下一句**的东西。
节奏由点击决定，所以每一句都要值得那一次点击。

---

## 一、句子长度

| 位置 | 长度 | 原因 |
|---|---|---|
| 单句台词 | 8~40 字 | 超过 40 字，一屏显示不下，玩家要等打字机播完 |
| 单节点台词数 | 1~3 句（独白场景可到 6 句） | 一个节点 = 一屏，太多就闷 |
| 选项文字 | 16 字以内 | 选项要一眼看完，不能读成句子 |

**硬性**：单句不写句号。句号把语气按死，读起来像念课文。
逗号、顿号、省略号、破折号都可以用；「……」用来表示停顿和未尽之言。

```
✗ 他说他会来。我等了很久。雨一直没停。
✓ 他说他会来……我等了很久
✓ 雨一直没停
```

---

## 二、说话人是哪一类

按这三类写，不要让所有角色都用一个腔调：

| 类型 | 特征 | 写法 |
|---|---|---|
| **话少的人** | 每次不超过 12 字，常用「嗯」「……」「不用」 | 靠沉默和动作传达，不解释内心 |
| **话多的人** | 一句接一句，会跑题、会自我纠正 | 允许 30~40 字，但要有一个明确的意思 |
| **说漂亮话的人** | 修辞漂亮，但回避真正的问题 | 语言好听，内容空 — 玩家要能感觉到不对劲 |

**一个角色怎么说话，要写进 `upsert_character` 的 `note` 里**，
后面章节才能保持一致。格式：`说话方式 / 口头禅 / 从不提的事`。

---

## 三、旁白

`who` 留空就是旁白。旁白不是「叙述剧情」，是**镜头**：

```
✗ 她看起来很伤心，因为她知道他要走了。
✓ 她低着头，手在口袋里攥着什么东西
```

只写看得见、听得见的。心理活动一律通过动作、语气、停顿来表达。
玩家自己会补上情绪。

旁白每次不超过 30 字，一个节点最多 2 句 —— 旁白多了就变成小说了。

---

## 四、留白

Galgame 最有力的地方是**没说出口的部分**。

- 重要的情绪不要直说。用一句闲聊、一次沉默、一个转移话题来承载
- 玩家自己拼出来的信息，比说出来的重十倍
- 一场戏结束时，最后一句要「停」得住 —— 不要用总结句收尾

```
✗ 我知道，你其实一直在骗我，我很难过，但我还是原谅你了。
✓ 「……你手上的伤，是那时候留的吧」
✓ 「嗯」
```

---

## 五、每句都要有信息

连续三句都没有新信息的，就是废戏，删掉：

- 重复上句意思的
- 单纯打招呼、寒暄、报站名的
- 「我们走吧」「好的」这种可以省略的推进

**例外**：刻意的重复是节奏。同一个句子在开头和结尾各出现一次，
中间隔了三百个节点，那是最有力的一击。这种重复要有意识，不能是偷懒。

---

## 六、战斗/紧张场景

紧张感来自**句子变短**，不是形容词变多：

```
✗ 气氛变得极其紧张，她的心跳加速，手心里全是冷汗，感觉随时会出事。
✓ 脚步声停了
✓ 在门外
✓ 她摇头
```

---

## 七、一段合格台词的例子

```
who: heroine
lines: [
  "你来得比我想的早",
  "票我买好了……两张",
  "万一你不来呢",
  "那就当我自己去"
]
```

35 字，四句，没有一句解释情绪，但把她的紧张、赌气、期待全放在了
「万一你不来呢 / 那就当我自己去」这两句里。这就够了。

**写完一段，自己读一遍**：如果每一句都在解释自己说了什么，重写。
