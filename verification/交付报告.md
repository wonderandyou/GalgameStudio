- `ui/frontend-verify.js`：仅在带测试 URL 参数时运行的 800 节点回归与截图脚本。
- `verification/run_browser.py`：真实 Edge 浏览器驱动、结果采集和截图脚本。

阶段权重为编剧 60%、美术 20%、配音 15%、装配 5%。时长预估公式为 `round(minutes × 300 ÷ 48 × 1.3)`。

## 六项实测

测试环境：Windows 本机 Edge 无头模式，1440 × 960；实际加载最终版 `index.html`，执行真实 DOM 点击、滑条事件、鼠标拖拽和缩放。800 个节点分为 2 幕、20 章，每章 40 节点。帧率测试解除浏览器垂直同步限制，避免把测试浏览器的软件合成节流误算为画布耗时。

1. **页面与控制台**：页面标题为“鲸落工坊 · Galgame Studio”，LiteGraph 实际装载 `800` 节点；`finalErrors: []`，未白屏、无 JavaScript 异常。
2. **五页切换**：项目 → `view-projects`，接口配置 → `view-setup`，剧情编排 → `view-editor`，试玩 → `player: true`，导出 → `view-export`。
3. **章节树**：DOM 返回 `acts: 2`、`chapters: 20`、`visible: true`；折叠后 `.act-chapters.collapsed` 数量为 `1`。点第 3 章后 LiteGraph 节点数 `40`、连线 `39`、全量数据仍为 `800`；活动章行数为 `1`。显示全部后恢复 `800` 节点、`780` 条有效连线。测试图每章以结局收尾，因此跨章不连出边，780 是输入数据的正确数量。
4. **800 节点性能**：120 帧拖拽与缩放的实测平均 `521.9 FPS`，帧间隔 P95 `4.1 ms`；完整重绘中位 `0.6 ms`、P95 `1.2 ms`；输入事件中位 `0.1 ms`、P95 `0.3 ms`。这些数字来自解除帧率上限的基准模式，不等同于每台桌面机器的固定刷新率，但 P95 低于 60 FPS 的 16.7 ms 帧预算。
5. **生成参数**：滑条设为 90 分钟后，DOM 返回“90 分钟”“预估 731 节点”，节点数最大值 `2000`；截获 `/generate` 请求参数为 `node_count: 8`、`branch_depth: 2`、`target_minutes: 90`。取消按钮请求的任务 ID 为 `job-cancel-check`，取消后面板隐藏。
6. **截图**：章节树、单章视图、生成进度均已实际渲染并截图；进度样例显示编剧工作中、第 3 章、已写 128 / 目标 980 节点、总体 26%。

完整原始断言见 `verification/results.json`，最终运行日志见 `verification/final-run.log`。
